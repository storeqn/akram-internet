# خدمات أكرم للإنترنت

موقع عربي للمنازل والمؤسسات في شمال البصرة. [الموقع المنشور](https://akram-internet.pages.dev/).

## طريقة العمل المبسطة

1. يملأ الزبون بياناته وعنوانه وموقعه ويراجع الطلب (حقول العنوان اختيارية عند تحديد الموقع).
2. يضغط «حفظ الطلب وفتح واتساب».
3. بعد تأكيد الحفظ من Google Sheets، يفتح الموقع رسالة واتساب جاهزة. يؤكد الزبون إرسالها داخل واتساب.
4. يدير صاحب الخدمة الطلبات والحالات والملاحظات داخل جدول Google Sheets الخاص، ويمكن تنزيله بصيغة Excel.

لا توجد لوحة إدارة منفصلة أو كلمات مرور أو API_SECRET أو Cloudflare Access أو Turnstile. رابط Apps Script يقبل الإضافة فقط ولا يعرض أي طلب أو يوفر عمليات تعديل عامة. يبقى الجدول خاصاً بحساب صاحبه.

عند فشل الحفظ تظهر رسالة حقيقية وإمكانية إعادة المحاولة أو استخدام «واتساب فقط»؛ لا يُعرض نجاح وهمي. يمنع النظام تكرار رقم الطلب، ويمنع تكرار المحتوى نفسه خلال خمس دقائق ضمن آخر 100 طلب.

## التشغيل

Node.js 22 أو أحدث، بدون حزم بناء إضافية:

```bash
npm test
npm run build
npm run preview
```

- `dist`: Cloudflare Pages، مع API للحفظ.
- `dist-pages`: GitHub Pages، واجهة وواتساب فقط.

إعداد Cloudflare: أمر البناء `npm test && npm run build`، المخرجات `dist`، المتغير الوحيد `APPS_SCRIPT_URL`.

راجع [SETUP.md](SETUP.md) لتفعيل الحفظ. لا يعمل حفظ الطلبات قبل نشر سكربت Google وربط رابط `/exec`.

## الخصوصية والاختبارات

الخادم لا يوفر قراءة بيانات العملاء. `/admin` و`/api/admin/*` غير متاحين. لا تُحفظ بيانات الزبون في localStorage أو IndexedDB أو Service Worker. البيانات في ذاكرة الصفحة حتى الحفظ إلى الجدول أو إرسالها إلى واتساب.

الخدمات الخارجية: Cairo وLeaflet وOpenStreetMap. GPS والتثبيت يتطلبان HTTPS ودعم المتصفح. الصفحة لا تطلب GPS إلا بعد ضغط الزبون الزر. عند تعذر الخريطة يمكن استعمال GPS أو رابط Google Maps.

الاختبارات تتحقق من صحة الحقول، ومنع التكرار، وفشل الحفظ، ومنع قراءة الطلبات وحقن صيغ الجدول. اختبارات Apps Script بمحاكاة خدمات Google؛ الاختبار الفعلي يحتاج نشره وتفويضه. لا تثبت الاختبارات وصول رسالة واتساب أو نجاح العمل على كل هاتف.

حقول المحافظة والقضاء والمنطقة ونقطة الدلالة مطلوبة فقط عند عدم تحديد موقع بالخريطة أو GPS أو رابط خرائط صحيح. حقل «أقرب رقم كابينة عليك» اختياري ويُضاف إلى رسالة واتساب وعمود جديد في الجدول. تحتفظ ترقية الجدول بعمود نوع الخدمة السابق والطلبات القديمة دون تغييرها.
