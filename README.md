# خدمات أكرم للإنترنت

[الموقع](https://akram-internet.pages.dev/) — طلب اشتراك عربي سريع عبر واتساب فقط.

## تجربة الطلب

- اسم عادي، دون اشتراط الاسم الثلاثي، ورقم هاتف عراقي.
- حقل واحد للعنوان أو أقرب نقطة دالة، ويمكن تركه عند تحديد الموقع بواسطة زر «استخدم موقعي الحالي».
- رقم الكابينة والملاحظات داخل قسم اختياري.
- زر «إرسال الطلب إلى واتساب» يفتح رسالة جاهزة فوراً، دون حفظ أو انتظار خادم أو نافذة مراجعة. يؤكد الزبون إرسال الرسالة داخل واتساب.
- تحديد الموقع يعمل بواسطة GPS فقط، بعد طلب صريح وموافقة الزبون؛ لا توجد خريطة يدوية أو خيار موقع ثانٍ.

لا يحفظ الموقع بيانات الطلب في جدول أو خادم أو تخزين المتصفح. Service Worker يخزن الأصول العامة فقط. تم تعطيل API الحفظ القديم برد 410 حتى للنسخ القديمة. البيانات السابقة في جدول Google لم تُحذف، والمشروع القديم في Apps Script لم يعد مرتبطاً بهذا الموقع.

## التشغيل والنشر

Node.js 22 أو أحدث، دون حزم بناء إضافية:

```bash
npm test
npm run build
npm run preview
```

- Cloudflare Pages: أمر البناء `npm test && npm run build`، المخرجات `dist`، الفرع `main`.
- GitHub Pages: workflow المرفق ينشر `dist-pages`.
- لا متغيرات بيئة أو مفاتيح أو إعداد Google مطلوبة للنسخة الحالية.

PWA مع أيقونات وتعليمات تثبيت وواجهة عدم الاتصال. يلزم الإنترنت لفتح واتساب، وHTTPS لاستخدام GPS والتثبيت.

الاختبارات تتحقق من الاسم البسيط والهاتف والعنوان البديل والرابط ورسالة واتساب وتعطيل الحفظ. فتح رابط واتساب لا يثبت إرسال الرسالة أو استلامها.

## الصور والموقع

سلايدر بثلاث صور أصلية مولدة للمشروع: الإنترنت السريع، الألعاب، والضوئي. الصور WebP مضغوطة داخل public/assets/banner-*.webp (نحو 50–61 KB لكل صورة). تبديل تلقائي كل 6.5 ثانية مع أزرار ونقاط وإيقاف مؤقت؛ يتوقف أثناء التركيز أو مرور المؤشر أو إخفاء التبويب، ويحترم تفضيل تقليل الحركة. حقل الكابينة ظاهر واختياري. أُزيل اختيار الموقع اليدوي على الخريطة؛ بقي GPS والعنوان البديل فقط.
