# خدمات أكرم للإنترنت

موقع عربي RTL للمنازل والدوائر الحكومية والشركات في شمال البصرة، بهوية كحلية وسماوية. الاتصال وواتساب: **+9647716470590**.

## التشغيل

يتطلب Node.js 22 أو أحدث. لا يحتاج حزم npm خارجية للبناء أو الاختبار.

```bash
npm test
npm run build
npm run preview
```

افتح `http://localhost:4173`. المعاينة ثابتة ولا تشغّل الحفظ أو المصادقة. الإنتاج وGPS وتثبيت PWA تتطلب HTTPS. لمعالجة الخادم محلياً يمكن استخدام أداة Cloudflare الرسمية: `npx wrangler pages dev dist` مع `.dev.vars` محلي.

## الوظائف

- صفحة تسويقية، خدمات، أسئلة شائعة، اتصال مباشر وواتساب.
- التحقق من الاسم الثلاثي والهاتف العراقي؛ دعم الأرقام العربية وصيغة +964.
- GPS بطلب صريح، Leaflet وOpenStreetMap، علامة قابلة للسحب ورابط Google Maps.
- مراجعة البيانات ورسالة واتساب منظمة. فتح واتساب ليس تأكيداً على الإرسال أو الاستلام.
- حفظ مؤكد بالخادم عند ربط Apps Script، مع Turnstile ومنع التكرار.
- إدارة الطلبات والبحث والتصفية وتغيير الحالة والملاحظات والاتصال والموقع والإحصائيات.
- مصادقة Cloudflare Access والتحقق من توقيع JWT والصلاحية والجمهور والبريد على الخادم. تُرفض الإدارة بالكامل إذا لم تضبط المصادقة.
- PWA وأيقونات PNG وواجهة انقطاع الاتصال. لا تخزين محلي للطلبات ولا تخزين مؤقت لمسارات API والإدارة.

## مسارا النشر

| المخرج | الاستخدام |
| --- | --- |
| `dist` | Cloudflare Pages: الواجهة والخادم والإدارة؛ يلزم ربط الخدمات |
| `dist-pages` | GitHub Pages: الواجهة والطلبات عبر واتساب فقط؛ لا لوحة إدارة ولا خادم |

لا تنشر جذر المستودع كملفات ثابتة. انشر مجلد البناء المناسب فقط. نشر `public` مباشرة يعرض ملفات واجهة الإدارة دون حمايتها بالخادم؛ لذلك استخدم `dist` عبر Cloudflare Pages حصراً للنسخة الكاملة.

التفاصيل وخطوات الأسرار والمصادقة: [SETUP.md](SETUP.md).

## الملفات

- `public/`: الواجهة والأصول وPWA وواجهة الإدارة.
- `server/worker.js`: API ومصادقة Cloudflare؛ يُدمج مع التحقق المشترك في `dist/_worker.js`.
- `apps-script/Code.gs`: الحفظ والمتابعة في جدول Google خاص.
- `tests/core.test.mjs`: تحقق بيانات، حدود المدخلات، حماية API، توقيع JWT حقيقي، دورة Apps Script بمحاكاة خدمات Google، ومنع التكرار وحقن الصيغ.
- `.github/workflows/pages.yml`: بناء واختبار ونشر النسخة الثابتة على GitHub Pages عند تفعيل Pages.

## حدود التحقق

نجحت 11 مجموعة اختبارات آلية والبناء. اختبارات Sheets تستخدم محاكاة وليست اتصالاً فعلياً بحساب Google. المعاينة في المتصفح تتحقق من عرض الواجهة ومراجعة الطلب فقط؛ لا تثبت استلام واتساب أو حفظ طلب إنتاجي أو نجاح دخول Access. يلزم اختبار قبول فعلي بعد الربط كما في SETUP.

الخطوط وLeaflet والخريطة وTurnstile خدمات خارجية تحتاج اتصالاً. يبقى تقديم طلب واتساب ممكناً عند تعذر الخريطة. لم تُضف أسعار أو شهادات أو آراء عملاء أو أرقام سرعة مختلقة.
